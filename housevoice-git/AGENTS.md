# HouseVoice Project Guidance

Before troubleshooting VACA connectivity, changing display network addresses, or
planning a router/new-house migration, read
[`docs/network-migration-vaca.md`](docs/network-migration-vaca.md). Preserve the
existing VACA config entries, pairings, devices, entities, dashboards,
automations, and Walkie configuration unless that guide's non-destructive
recovery has been ruled out with evidence.
